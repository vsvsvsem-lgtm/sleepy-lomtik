# Молочноломтиковые сны

Журнал сна малышки. Один файл `index.html`, без сборки. Записи хранятся на устройстве (у каждого устройства свой журнал).

## Публикация на GitHub Pages
1. На github.com создай репозиторий (например `sleep-journal`), тип Public.
2. Загрузи в него файлы `index.html`, `.nojekyll`, `README.md` (Add file → Upload files).
3. Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты приложение откроется по адресу `https://<твой-логин>.github.io/sleep-journal/`.
5. На телефоне открой ссылку и выбери «Добавить на экран «Домой»», тогда оно запускается как приложение.
